## 2026-08-11 - Localized Loading Feedback and Dynamic ARIA Labels on Icon-only Buttons
**Learning:** For a smoother, less disruptive user experience, background data refreshes should use localized loading feedback (e.g., adding a rotation class to the inner icon element and disabling the button) rather than a global page-blocking overlay. Additionally, interactive state toggles (like theme toggles) must have their `aria-label` dynamically updated alongside their physical icon representation to stay aligned for assistive technologies.
**Action:** When designing icon-only buttons with state or background actions, wrap the icon character/element in a span to prevent layout shifts during animation, and always update the element's `aria-label` whenever the title or visual text changes.
